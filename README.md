# Python Automation Tool - File Organizer

## Project Overview
Python Automation Tool is a simple project that automatically organizes files into different folders based on their file types.

## Features
- Automatically creates sample files.
- Organizes text and PDF files into the Documents folder.
- Organizes image files into the Images folder.
- Creates folders automatically.
- Saves time and reduces manual work.

## Technologies Used
- Python
- OS Module
- Shutil Module

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Run file_organizer.py.
4. The program creates an automation_demo folder and organizes the sample files.

- Learned file handling in Python.
- Learned how to create folders automatically.
- Learned file management using Python modules.
- Practiced Python automation.
